# Innovision - الابتكار والتحول الرقمي

![Innovision Logo](https://img.icons8.com/fluency/96/000000/microchip.png)

موقع Innovision هو منصة رقمية متكاملة تقدم استشارات وحلولاً في مجالات الذكاء الاصطناعي، التعلم الآلي، والأنظمة البيومترية.

## 🚀 الميزات الرئيسية

- **ثلاث لغات**: العربية، الإنجليزية، الفرنسية
- **مساعد آلي ذكي**: قائمة منسدلة للإجابة على الاستفسارات
- **دراسات حالة**: عرض مشاريع سابقة مع روابط مباشرة
- **نموذج طلب خدمة**: مع أرقام هواتف دولية (25 دولة)
- **تكامل مع EmailJS**: إرسال الطلبات مباشرة إلى البريد الإلكتروني
- **تصميم متجاوب**: يعمل على جميع الأجهزة
